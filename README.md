🚀 Desenvolvimento Orientado a Objetos — UC06 (Senac EAD)
Repositório dedicado aos projetos e atividades práticas desenvolvidas na Unidade Curricular Desenvolver Código Orientado a Objetos do curso Técnico em Desenvolvimento de Sistemas no Senac EAD.

☕ Conceitos Práticos Aplicados
Classes e Objetos: Criação de classes, atributos, métodos, encapsulamento (get/set) e utilização de construtores.
Associação e Manipulação de Dados: Gestão de pacotes, conversões monetárias e cálculos lógicos em Java.
Herança e Polimorfismo: Utilização de classes abstratas, métodos abstratos e hierarquias de classes para reutilização de código.
Interfaces e Listas: Implementação de contratos via interfaces e manipulação de coleções de objetos em Java.

📂 Estrutura das Atividades Desenvolvidas

🔹 Atividade 01 — Sistema de Gestão para Agência de Viagens
Descrição: Sistema em Java (tipo console) estruturado com classes para gerir meios de transporte, hospedagens, pacotes de viagens e dados de vendas de clientes.
Funcionalidades Principais:
Cálculo de custos totais de hospedagem e pacotes com margem de lucro e taxas adicionais.
Conversão de valores entre Reais (R$) e Dólares (US$) com base na cotação informada.
Interação via classe principal (main) para cadastro de pacotes e conversões.
Conceitos: Classes, atributos, construtores, métodos de cálculo e formatação de saídas.

🔹 Atividade 02 — Sistema de Recursos Humanos (RH) e Folha de Pagamento
Descrição: Sistema orientado a objetos focado na gestão de funcionários assalariados e horistas, implementando regras específicas de remuneração e reajustes salariais.
Funcionalidades Principais:
Utilização de classe abstrata para funcionário e derivação para os tipos específicos (assalariado e horista).
Aplicação de polimorfismo no cálculo dinâmico de pagamentos e aplicação de aumentos gerais baseados em percentuais informados pelo utilizador.
Registo e listagem unificada de até 10 funcionários numa única lista, exibindo dados e pagamentos antes e depois do reajuste.
Conceitos: Herança, classes abstratas, polimorfismo, encapsulamento e estruturas de repetição.

🔹 Atividade 03 — Módulo Contábil e Cálculo de Impostos
Descrição: Módulo desenvolvido para representar e calcular impostos e contribuições complexas sobre vendas de produtos (como PIS e IPI).
Funcionalidades Principais:
Implementação de interfaces e hierarquia de classes para padronizar o comportamento de cálculo e descrição dos impostos.
Classe Pagamentos contendo o nome da empresa e uma lista dinâmica de impostos associados.
Cadastro contínuo de múltiplos impostos via consola até que o utilizador decida encerrar com o comando de parada.
Conceitos: Interfaces, hierarquia de classes, listas dinâmicas e tratamento de entradas do utilizador.
